Modelové srovnání

Poissonův model používá očekávané střely = průměr vlastní střelecké aktivity a soupeřem povolených střel. Předpokládá nezávislost, nezohledňuje domácí prostředí, sestavy ani tempo hry. Výsledky nejsou garancí úspěšnosti sázek. Remíza je samostatný výsledek; vyhodnocení závisí na pravidlech sázky.

Ověřené zápasy

Zdroj: NHL Web API. Data se načítají přes server aplikace, nikoliv přímo z mobilního prohlížeče. Historie je z dokončených zápasů základní části, pokud ji API poskytuje. Čas aktualizace se ukáže po načtení.
